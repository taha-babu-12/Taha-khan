## Featured Project

### [alidev](https://github.com/taha babu/alidev)

> Ultra-fast, autonomous AI pair-programmer and vibe-coding terminal agent

`alidev` is a terminal-native coding assistant built for Android Termux, Windows, macOS, and Linux. It supports multi-provider AI backends, agent workflows, smart file editing, context memory, and project automation.

#### Highlights
- 🤖 Multi-provider AI support with fallback logic
- 🧠 PLAN and AGENT modes for different workflows
- 🛠️ Smart code editing and diagnostics
- 📁 Project memory and session persistence
- ⚡ Built for Termux and desktop developer environments
- 🔌 Plugin-capable architecture
